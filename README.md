# Java Practice & Collaboration

A collaborative repository for learning Java, practicing programming fundamentals, and improving Git and GitHub workflow.

## About

This repository contains Java practice programs written while learning and exploring core programming concepts. It also serves as a space to practice collaborating on code using Git and GitHub.

## What You'll Learn

* Java syntax and fundamentals
* Variables, data types, and operators
* Conditional statements and loops
* Methods and functions
* Object-Oriented Programming (OOP)
* Problem-solving and logical thinking
* Git and GitHub collaboration

## Tech Stack

* **Language:** Java
* **Version Control:** Git
* **Platform:** GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hrefabdullah/java_practice_collab.git
```

### 2. Navigate to the project

```bash
cd java_practice_collab
```

### 3. Compile and run a Java program

```bash
javac FileName.java
java FileName
```

Replace `FileName` with the name of your Java file.

Make sure Java JDK is installed on your system.

## Collaboration Workflow

1. Clone the repository.
2. Create a new branch for your changes.
3. Write and test your Java programs.
4. Commit your changes with a meaningful message.
5. Push your branch to GitHub.
6. Open a Pull Request for review and collaboration.

## Repository Goals

* Practice Java consistently.
* Strengthen programming fundamentals.
* Learn through hands-on coding.
* Improve teamwork and version control skills.
* Build a foundation for more advanced Java projects.
